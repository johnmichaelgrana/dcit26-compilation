
# dcit26-compilation

A compilation of Flutter and Dart laboratory activities
for DCIT 26 – Application Development and Emerging Technologies.

## Laboratory Activities

### Lab 1 – Hello World: `lab1_hello_world/`

A basic Flutter application that displays Hello World!

### Lab 2 – Student Profile: `lab2_student_profile/`

A student profile displaying personal information.

### Lab 3 – Input and List: `lab3_input_list/`

A Flutter application that accepts user input and
displays items in a dynamically updated list.

### Lab 4 – Modal and Scrolling: `lab4_modal/`

An application demonstrating modal dialogs,
images, and scrollable content.

### Lab 5 – Navigation: `lab5_navigation/`

Navigation between Home, Profile, and About screens
using Flutter Navigator and Drawer.

### Lab 6 – Passing Product Data: `lab6_products/`

A product list application that passes the selected
Product object to a detail screen.

### Lab 7 – Networking: `lab7_networking/`

A Flutter application that retrieves and displays
random user profiles using an HTTP API.

## How to Run a Laboratory

1. Open the desired laboratory folder.
2. Run `flutter pub get`.
3. Select a supported device or emulator.
4. Run `flutter run`.
